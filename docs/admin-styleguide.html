Stijlgids

Referentie voor nieuwe adminpagina's. Alle patronen zijn afgeleid uit de bestaande code. Nieuwe pagina's volgen dit patroon zonder uitzondering.

01

Het admin-palet is donkerder dan de app: de nav gebruikt #0d0d0d — één tint dieper dan de pagina-achtergrond.

02

Navigatie

De nav is identiek op elke adminpagina. Gebruik de navLinkStyle functie exact zoals hieronder.

NAV-VOLGORDE

Links (gecentreerd):

USERS› CRONS› ARNOBOT› BLOGS› META› FEEDBACK

Rechts:

ARNO.BLOG | UITLOGGEN

CODE

const navLinkStyle = (active: boolean): React.CSSProperties => ({
  color: active ? '#f59e0b' : '#9ca3af',
  textDecoration: 'none',
  fontSize: '15px',
  letterSpacing: '3px',
  fontWeight: 700,
  padding: '6px 20px',
  borderRadius: 4,
  background: active ? '#1e293b' : 'none',
})
// Nav-structuur: grid 1fr auto 1fr, height 56, bg #0d0d0d, borderBottom 1px solid #1e293b

03

Elke adminpagina heeft dezelfde drie lagen: main, nav, en een div-container.

04

Typografie

Adminpagina's gebruiken system sans-serif. Space Mono en Bebas Neue verschijnen alleen in client-components die AI-output renderen.

05

Knoppen

Admin-knoppen gebruiken borderRadius: 4 (niet 999). App-knoppen in client-components mogen de app-norm volgen.

// Primair
{ background: '#f59e0b', color: '#000', border: 'none', padding: '10px 24px', fontWeight: 700, fontSize: '14px', letterSpacing: '2px', borderRadius: 4 }
// Secundair
{ background: 'transparent', border: '1px solid #374151', color: '#6b7280', borderRadius: 4 }
// Destructief
{ background: 'transparent', border: '1px solid #cc2200', color: '#cc2200', borderRadius: 4 }
